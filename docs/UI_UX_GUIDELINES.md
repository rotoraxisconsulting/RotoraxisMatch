# UI/UX Guidelines — RotoraxisMatch

The app must look like a premium B2B SaaS.

## Visual style

- clean
- modern
- aviation-inspired
- trustworthy
- professional
- mobile-first
- responsive on web
- light base
- navy/blue/cyan accents
- clean cards
- soft borders
- clear hierarchy
- good spacing
- readable typography

## UX principles

- The user must always understand where they are.
- Main actions must be obvious.
- Technician cards must be easy to scan.
- Filters must be easy to use.
- Contact privacy must be clearly explained.
- Requests must show clear status.
- Admin actions must be direct and safe.

## Mobile

- Avoid big tables.
- Use cards and lists.
- Use filters in panels/modals.
- Use large tap targets.
- Keep navigation simple.
- Prioritize search, map and requests.

## Web

- Use wider layouts.
- Sidebar dashboards are allowed.
- Grids and tables are allowed if responsive.
- Landing should feel like a polished SaaS site.

## Components

Use reusable components:
- Button
- Card
- Badge
- MetricCard
- EmptyState
- SectionHeader
- TechnicianCard
- TechnicianFilters
- MatchRequestCard
- DemoModeBanner
- RoleSwitcher
